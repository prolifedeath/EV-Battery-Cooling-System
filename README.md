 EV Battery Cooling System using IoT and AI/ML

This project develops an intelligent battery monitoring and cooling system using ESP32, IoT, and Machine Learning.

 Features
- Battery voltage, current, and temperature monitoring.
- Automatic cooling fan control.
- Real-time monitoring using Blynk IoT.
- Battery condition classification using Random Forest ML.

 Technologies
ESP32, Python, Arduino IDE, Blynk, Pandas, NumPy, Scikit-learn.

 Machine Learning
The model uses synthetic battery data to classify battery conditions into Normal, Warning, and Critical.

 Project Domain
IoT | Artificial Intelligence | Machine Learning | Electric Vehicles
